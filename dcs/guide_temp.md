# 建议按如下段落结构描述工作流
  **1. 流程简介**：流程简介
  **2. 版本信息**：版本信息以及该版本更新内容
  **3. 流程步骤**：请描述WDL中的重要task的描述。用户看到的报错和流程相关的主要是以WDL的task为维度的，因此需要描述重点tasks，并且对经常报错的task提示用户可能报错的原因。
  **4. 参数介绍**：输入参数介绍和数据格式解释，包含参数的入参，需要默认到公共库的公共数据
  **5. 结果**：结果文件说明
  **6. 资源建议**：运行该流程所需的资源建议
  **7. 相关流程以及版本**：请描述其他相关流程名称和版本号
  **8. GitHub 链接**：如软件链接其余页面，请在此描述，如软件的GitHub页面，注意链接到对应版本分支。【选填】
  **9. 参考基因组**：请描述流程所需的参考基因组【选填】
  **10. 费用说明示例**：费用说明和示例（不同数据量，运行资源以及费用）
  **11. 其他**：该流程工具相关的注意事项，提醒云平台流程操作指引，投递流程指引，demo项目地址链接
  **12. 引用信息**
